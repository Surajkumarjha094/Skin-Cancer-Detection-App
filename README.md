# 🩺 Skin Cancer Detection App

A **web-based application** for detecting and analyzing skin cancer using advanced imaging technology. Helps users capture skin lesion images, get analysis results, and track scan history—all from a responsive web interface.

**GitHub Description:**  
> Web app for skin cancer detection with image capture, analysis, education, and scan history tracking.

---

## ✨ Features

- 📸 **Camera Capture** – Take photos of skin lesions directly from your device  
- 🔍 **Analysis Results** – Detailed insights and analysis of skin abnormalities  
- 📚 **Education Panel** – Learn about skin cancer prevention and detection  
- 📊 **Scan History** – Track and review previous scans  
- 📱 **Responsive Design** – Works on desktop and mobile devices  

---

## 🏗️ Technology Stack

- **Frontend:** React 18 + TypeScript  
- **Build Tool:** Vite  
- **Styling:** Tailwind CSS + shadcn/ui components  
- **Routing:** React Router v6  
- **State Management:** TanStack Query  
- **UI Components:** Radix UI primitives  

---

## 🚀 Getting Started

### Prerequisites

- Node.js v16+  
- npm or yarn  

### Installation

```bash
# Clone the repository
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start development server
npm run dev
```

Open your browser and navigate to `http://localhost:5173`  

---

## 📋 Available Scripts

- `npm run dev` – Start development server  
- `npm run build` – Build for production  
- `npm run preview` – Preview production build  
- `npm run lint` – Run ESLint
